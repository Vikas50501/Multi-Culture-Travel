# Multi Culture Travel World

A modern, responsive travel agency website template tailored for **Multi Culture Travel World** (Calgary, AB — Serving Canada since 1992).

## Key Features
- **Hero Background**: High-contrast, cinematic travel visual with clear logo and navigation visibility.
- **About Section**: Professional office and advisor presentation ("Who We Are").
- **Popular Destinations Slider**: Authentic, high-resolution photography for India, Pakistan, Dubai, Mexico, Hawaii, Las Vegas, and Europe.
- **From Our Travellers (Gallery)**: Curated packages for the Sikh Pilgrimage (Panja Sahib), Dubai Luxury & Desert Safari, and All-Inclusive Resort Escapes with theme-matching pastel cards.
- **Enquiry Form**: Direct enquiry booking form routed to Calgary agents.

## Repository Contents
- `tripora-theme/` — Full responsive website source code (HTML5, Tailwind CSS 4, JS, images, fonts)
- `tripora-theme.zip` — Ready-to-deploy zip distribution
